Hi! Welcome to your first step on the software engineering staircase. 
This project is a fully completed website that acts as a template for review platforms. The original intention of the application was to be a website where job application candidates review companies based on the application process, like Glassdoor.
**However**, I have decided to make the project an open-source app, which software lovers can use as a template for their first web app. This is because I know how challenging designing a web application from scratch can be. 
Feel free to clone the repo on your laptop, study the code and the flow of operations, then make your changes! Change the design, layout, or the backend logic of the application.
